# KinDock.family website

Plain HTML, no build step. Cloudflare Pages publishes it straight from this repository.

- `index.html`: the whole page
- `img/`: screenshots and the icon
- `404.html`, `robots.txt`, `sitemap.xml`, `_headers`: used by Cloudflare Pages

To change the site, edit a file on GitHub and commit. Cloudflare publishes the change in about a minute.
